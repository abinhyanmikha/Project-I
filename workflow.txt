VIDEO GAME GLOBAL SALES PREDICTION — PROJECT WORKFLOW
======================================================

Goal
----
Predict a video game's Global_Sales (millions of units) from post-release
information (platform, genre, publisher, developer, review scores/counts,
platform age), and present the dataset, the model's performance, and its
predictions in an interactive Streamlit app.

Environment
-----------
- Python 3.12 inside the project virtual environment (venv/).
- Key libraries: pandas, numpy, scikit-learn 1.9, xgboost 3.4, joblib,
  matplotlib, seaborn, streamlit.
- Run every step with the project venv:
      .\venv\Scripts\python.exe <command>
- Install dependencies:
      pip install -r requirements.txt


STEP 1 — Collect the dataset
----------------------------
- Raw source: Video_Games_Sales_as_at_22_Dec_2016.csv (the "vgsales" dataset,
  16,719 records x 16 columns).
- Load it with pandas (see data1 copy 2.ipynb, first code cell):
      df = pd.read_csv(Data_path)

STEP 2 — Explore the data
-------------------------
- Inspect shape, dtypes, df.info(), and df.describe().
- Check duplicate rows, missing values per column, and the release-year range.
- Look at the distribution of Global_Sales (heavily right-skewed) and of the
  categorical columns (Platform, Genre, Publisher, Developer, Rating).

STEP 3 — Clean the dataset
--------------------------
- Remove genuine duplicate records.
- Drop rows with no target value: df.dropna(subset=["Global_Sales"]).
- Drop rows with no Name (bookkeeping rows).
- Drop rows missing Year_of_Release.
- Keep only rows with at most 2 missing values among the key categorical
  columns (Rating, Publisher, Developer):
      df = df[df[categorical_features].isnull().sum(axis=1) <= 2].copy()
- Result saved as: video_game_sales_cleaned.csv

STEP 4 — Exploratory data analysis (EDA)
----------------------------------------
- Visualize sales by genre, platform group, publisher, and year.
- Confirm the heavy skew of Global_Sales and inspect log(1 + sales):
      df["Global_Sales_log"] = np.log1p(df["Global_Sales"])
  The log transform is used for analysis and for the baseline models.

STEP 5 — Feature engineering
----------------------------
Derived features added to the cleaned data:
- Game_Age                = reference_year - Year_of_Release
                            (reference_year = df["Year_of_Release"].max())
- Has_Review_Scores       = 1 if any critic/user review data exists, else 0
- Review_Total_Count      = Critic_Count.fillna(0) + User_Count.fillna(0)
- Critic_User_Gap         = User_Score * 10 - Critic_Score
- Is_Major_Publisher      = 1 if Publisher is a major publisher, else 0
- Platform_Group          = Platform mapped to family
                            (Nintendo / PlayStation / Xbox / PC / Sega /
                             Atari / Other / Unknown)

Leakage guard
-------------
- The 'Name' column and the regional sales columns (NA_Sales, EU_Sales,
  JP_Sales, Other_Sales) are EXCLUDED from the model features to avoid
  target leakage.

STEP 6 — Preprocessing for modeling
-----------------------------------
- Features used for the model:
    numeric_features     = Game_Age, Has_Review_Scores, Review_Total_Count,
                           Critic_User_Gap, Critic_Score, Critic_Count,
                           User_Score, User_Count, Is_Major_Publisher
    categorical_features = Platform, Genre, Rating, Publisher, Developer
    target               = Global_Sales
- Split (random holdout, reproducible):
      X_train, X_test, y_train, y_test = train_test_split(
          X, y, test_size=0.20, random_state=42)
- Group-wise imputation, grouped by (Genre + Game_Age):
    * numeric columns   -> group median, global median as fallback
    * categorical cols  -> group most-frequent, global most-frequent fallback
    (Genre itself is not imputed because it is a grouping column.)
- One-hot encoding of the categorical columns:
      OneHotEncoder(handle_unknown="ignore", min_frequency=10,
                    sparse_output=False)
- Final design matrix: numeric columns + encoded columns
  = 4,105 training rows / 3,284 test rows x 427 features, no missing values.

STEP 7 — Train and compare models
---------------------------------
- Candidate models (all with random_state=42):
    Linear Regression, Decision Tree, Random Forest, XGBoost.
- Baseline runs fit on the log target: y_train_log = np.log1p(y_train),
  predictions converted back with np.expm1() before scoring.
- Compare on the held-out test set using MAE, RMSE, and R2.
- XGBoost was the best of the baselines.

STEP 8 — Hyperparameter tuning
------------------------------
- Tune XGBoost with RandomizedSearchCV:
      estimator = XGBRegressor(objective="reg:squarederror", random_state=42)
      param_distributions = {n_estimators, max_depth, learning_rate,
          subsample, colsample_bytree, min_child_weight, gamma,
          reg_alpha, reg_lambda}
      n_iter=30, cv=5, scoring="neg_root_mean_squared_error", random_state=42
- The tuned model is fit on the RAW target (y_train) and predicts on the
  original sales scale directly.

STEP 9 — Evaluate the tuned model
---------------------------------
- Final tuned XGBoost performance on the 3,284-row test set:
      MAE  = 0.4142
      RMSE = 1.6326
      R2   = 0.3706
- Inspect permutation feature importance to confirm sensible drivers.

STEP 10 — Save the pipeline artifacts
-------------------------------------
Saved into the project root and consumed by the app:
- video_game_sales_cleaned.csv  — cleaned + engineered dataset
- best_xgboost_model.pkl        — tuned XGBoost regressor (joblib)
- X_test_processed.csv          — encoded test features (3,284 x 427)
- y_test.csv                    — test targets (original scale)

STEP 11 — Build the Streamlit app (app.py)
------------------------------------------
- Loads the four artifacts above and recomputes predictions/metrics on start.
- Reindexes the test features to the model's stored column order:
      X_test.reindex(columns=model.feature_names_in_, fill_value=0)
- Four pages via sidebar navigation:
    * Dashboard         — headline metrics + Global_Sales distribution
    * Dataset           — cleaned dataset with column search + download
    * Model Performance — MAE / RMSE / R2 + actual-vs-predicted scatter
    * Predictions       — prediction table, error distribution, CSV download
- Shows a clear message if any required artifact is missing.

STEP 12 — Test and run
----------------------
- Run the app with the project venv:
      .\venv\Scripts\python.exe -m streamlit run app.py
- Open the local URL (default http://localhost:8501) and check all pages.
- Deploy publicly if desired (e.g. Streamlit Community Cloud).
